# ⚡ DevMind AI Assistant

**AI assistant in every text field — free forever, runs 100% locally on your device, no API key needed.**

[![Chrome Web Store](https://shields.io)](https://google.com)
[![License: MIT](https://shields.io)](https://opensource.org)
[![Privacy](https://shields.io)](#privacy-first)

DevMind brings intelligent AI assistance directly into any website you visit (GitHub, Stack Overflow, Gmail, Notion, Google Docs) without sending a single byte of data to external cloud servers.

---

## ✨ Key Features

- 🌐 **Works Everywhere:** Activates automatically in any text field or via right-click context menu.
- 🔒 **100% Local & Private:** Powered by **Chrome Built-in AI (Gemini Nano)** and **Ollama** (`localhost:11434`). Zero cloud APIs, zero tracking.
- 💻 **Code Intelligence:** Debug, optimize, document, and review code across 50+ programming languages.
- 💡 **One-Click Smart Actions:** Translate, summarize, rewrite, and explain selected text instantly.
- ⌨️ **Fast Workflow:** Press `Ctrl+Shift+A` anywhere to toggle the draggable floating AI panel.
- 💬 **Per-Site Context:** Keeps conversation history organized by website.

## 🚀 Quick Start

1. **Install** [DevMind AI Assistant](https://google.com) from the Chrome Web Store.
2. *(Optional for Ollama users)* Make sure your local Ollama server is running at `http://localhost:11434` with CORS enabled for Chrome extensions (`OLLAMA_ORIGINS="*"`).
3. Click any text field or select text on any webpage, or press **`Ctrl+Shift+A`**.
